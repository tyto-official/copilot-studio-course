  <section class="scenario-band" id="scenariot">
    <div><div class="section-label">LYSERNO PRODUKTAGENT</div><h2>Från produktfråga till genomförd åtgärd</h2></div>
    <p>En medarbetare beskriver vad ett showroom behöver. Agenten hittar produkter i katalogen, kontrollerar pris och disponibelt saldo i SharePoint och läser företagets påfyllningsregler. Efter medarbetarens bekräftelse reserverar agentflödet varorna om villkoren är uppfyllda. Andra giltiga begäranden skickas för manuell granskning. <a class="scenario-link" href="https://tyto.se/lyserno">Besök Lysernos publika webbplats</a></p>
  </section>
